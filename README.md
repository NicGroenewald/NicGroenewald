## About Me

I'm in my 3rd year of Computer Systems at MTU Cork. Most of what I build starts out as Python, though a fair bit of it has since grown a React frontend whether I planned that or not.

The project I keep coming back to is **[ML-Visualizer](https://github.com/NicGroenewald/ML-visualizer)**. You hand it a fitted scikit-learn model and it opens a browser UI showing the real tree, then traces a query point down through it so you can see exactly which splits it hit. FastAPI on the backend, React on the front, pytest covering the extractors and the server.

**[PI-IOT](https://github.com/NicGroenewald/PI-IOT)** came out of wanting my Tuya smart plugs to be controlled from a custom command centre. It's an MQTT dashboard that runs on a Raspberry Pi on the local network, React and Vite on the front, Python behind it.

My day job is managing PcMaestro, a PC repair shop in Cork, Ireland. I've ended up writing most of the software it runs on. There's a sync that keeps the till system and the Shopify store in agreement, and a check-in system that tracks every repair from drop-off to collection. Both are private repos, but they're where I've learned the most.

What actually interests me is ML, and specifically not treating models as black boxes. That's most of why MLvis exists in the first place.

Currently looking for a software engineering placement starting January 2027.
